# Thuong Tin Homebrew Tap

Homebrew casks for Thuong Tin apps.

## Lid Awake

Lid Awake currently supports Apple Silicon Macs only.

```bash
brew tap thuongtin/tap
brew install --cask lid-awake
```

The cask installs the signed and notarized DMG from the official GitHub release:

https://github.com/thuongtin/lid-awake/releases
